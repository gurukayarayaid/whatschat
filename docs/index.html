Cara Install

Terpasang dalam 4 langkah

APK ini diinstal di luar Google Play, jadi izinkan sumber tidak dikenal.

  1. 1

    Unduh file APK

    Tekan tombol Unduh APK di halaman ini. File whatschat-1.0.apk (~30 MB) akan tersimpan di perangkatmu.

  2. 2

    Izinkan sumber tidak dikenal

    Buka Pengaturan → Aplikasi → Install unknown apps, lalu izinkan browser yang kamu pakai untuk menginstal aplikasi.

  3. 3

    Instal aplikasinya

    Buka file APK dari notifikasi atau FileManager, ketuk Install, dan tunggu hingga selesai.

  4. 4

    Mulai ngobrol

    Buka WhatsChat, masuk, dan nikmati percakapan yang aman. Selesai!

Ya. Aplikasi ini gratis diunduh dan digunakan, tanpa iklan.

Ya, file APK berasal langsung dari proyek ini dan dipublikasikan lewat GitHub Pages. Pastikan kamu mengunduh dari halaman resmi repositori.

Perangkat Android apa yang didukung?

Android 7.0 (Nougat) ke atas. Aplikasi dioptimalkan untuk layar modern dan mode gelap.

Bisakah saya memakai WhatsChat di banyak perangkat?

Bisa. Fitur sinkronisasi multi-perangkat memungkinkan kamu menautkan perangkat lain dan tetap menerima pesan.

Siap ngobrol dengan lebih aman?
